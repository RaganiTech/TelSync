# Security Policy (سیاست امنیتی) 🔒

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability (گزارش آسیب‌پذیری‌های امنیتی)

Security and privacy are the highest priorities of TelSync. Because this application processes sensitive contact books and Telegram sessions locally, we take every security report seriously.

### How to Report:
- **Do NOT open a public GitHub issue** for undisclosed security vulnerabilities.
- Please email the security report directly to the maintainer or submit a Private Vulnerability Report via GitHub Security Advisories:
  - Repository: `https://github.com/alireza00138300/contact-bridge/security/advisories`

### Response Timeline:
- Initial acknowledgment: Within 48 hours.
- Status update and reproduction: Within 5 business days.
- Fix and patch release: As soon as verified.
